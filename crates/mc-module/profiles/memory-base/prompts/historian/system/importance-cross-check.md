### Importance is not coupled to activity type

A small task can be 85+ if it settled a rule all future work must respect. A long discussion can be 30 if the conclusion was obvious in retrospect. A routine reply can be 70 if it committed the user to a deadline.

**Cross-check examples:**
- A conversation that settled "never book anything before the user confirms the dates" → 85+ (future work must respect this).
- Rescheduling one appointment → 20 (the calendar shows the result).
- Choosing one contractor over two others, with the reasons → 75 (the reasons matter when the choice is revisited).
- Sending a routine acknowledgement → 15.
