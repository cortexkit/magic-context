# v0.47.0 (draft)

## Reasoning retention is measured in tokens

- `keep_reasoning_tokens` replaces `clear_reasoning_age`, with a fixed **10,000-token default** on every model. Set a number or a per-model object, for example `{ "default": 10000, "openai/*": 6000, "anthropic/claude-opus-5-5": 20000 }`. Resolution tries exact and shorter model keys, the provider wildcard, then `default`.
- Reasoning is kept newest first in whole assistant steps. The first step that does not fit sets the cutoff for the older prefix. The newest assistant and reasoning-exempt step count but cannot be removed. Reported reasoning counts win over plaintext estimates; opaque reasoning without either costs a fixed 1,000 tokens per step.
- Removal only rides cache rebuilds that were already permitted. Defer passes replay the frozen ids and watermarks unchanged, signed-thinking models retain their oldest-prefix stop rule, and increasing the budget never restores removed reasoning.
- `clear_reasoning_age` is ignored with a warning. `doctor` removes it without guessing an age-to-token conversion, and explains how to replace a low-age override.
- OpenCode 1/2, Pi/OMP, and the Rust module share the cutoff rules. The dashboard and configuration reference expose the new scalar/per-model setting.
- Rust processed-image retirement no longer borrows the reasoning-age cutoff. New image selections use the TS/Pi dropped-tag watermark on rebuilds; old frozen image decisions still replay unchanged. This is a one-time policy change at the next rebuild for affected legacy Rust sessions, including users with non-default `clear_reasoning_age` overrides.

Historical offline replay is pending a separately supplied sanitized numeric snapshot; live stores were not accessed. The fixed default is a user ruling, not an inference from synthetic replay.
