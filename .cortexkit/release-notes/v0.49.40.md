# v0.49.40

This patch fixes history compaction on OpenCode 2 for sessions that used tools before their first summary.

## Upgrading

- Restart OpenCode after updating. No database migration is needed.

## Fixed

- **OpenCode 2 stopped compacting history after a session's first summary:** once a session had a summary that covered tool calls, every turn logged `v3 host fold: capture unavailable: Error: Native carrier has no source row coordinate`. From then on, Magic Context couldn't fold history into OpenCode 2's own compaction for that session, and a later compaction refused the turn with `Manual compaction controls have not been captured`. OpenCode 2 sends tool results without a message id, and a tool result whose call was already summarized was kept on its own, with no message to attach it to. A tool result now stays or goes together with the message that made its call, in the same step that attaches messages to OpenCode's stored rows. Sessions affected before the update recover on their next turn. Thanks to @botbeech for the precise report and reproduction (#875).
