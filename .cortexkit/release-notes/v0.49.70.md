# v0.49.70

This patch fixes summaries on Oh My Pi 19.1 and two `doctor` gaps for Pi and Oh My Pi users.

## Upgrading

Update with `npx @cortexkit/magic-context@latest`. No database migration is needed.

## Fixed

- **Summaries failed on Oh My Pi 19.1:** Oh My Pi 19.1.0 switches on its Auto-QA issue reporter in every run, including Magic Context's hidden summary and maintenance runs, which ask for no tools. Magic Context refuses any hidden run that has a tool, so on 19.1.0 every summary failed, and long sessions could end up refusing turns. Hidden runs on Oh My Pi now turn Auto-QA off with Oh My Pi's own setting. Your own Oh My Pi sessions and plain Pi are unchanged.
- **`doctor --fix` now repairs Pi (#961, thanks @VibePDF):** `--fix` never reached the Pi doctor, so only `--force` could repair a Pi install. `--fix` now repairs Pi's config and clears stale extension caches, and `--force` clears them even when they look current. Before clearing, the doctor now checks that no running Pi or Oh My Pi still has those files or Magic Context's database open. If one does, it leaves the cache alone and names the process to quit. If it can't check, it refuses, as it already did for OpenCode.
- **Oh My Pi users get the real upgrade path (#961):** the doctor can't change the plugin Oh My Pi has installed. With `--fix` or `--force` it now says how to upgrade: run `omp plugin install @cortexkit/pi-magic-context@latest`, then restart running Oh My Pi sessions. Config repairs for Oh My Pi still need `--force`.
