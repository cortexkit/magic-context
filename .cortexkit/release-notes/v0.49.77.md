# v0.49.77

This patch makes Magic Context load again on Oh My Pi 19.2.0.

## Upgrading

Update the plugin with `npx @cortexkit/magic-context@latest doctor`, then restart Oh My Pi. No database migration is needed. OpenCode and Pi users are not affected and can update whenever they like.

## Fixed

- **Oh My Pi 19.2.0 refused to load the Magic Context extension.** Oh My Pi 19.2.0 no longer accepts an extension that imports Pi's terminal UI package, so Magic Context did not start: sessions ran without context management. The extension now uses the terminal UI of the host it runs in. On Oh My Pi 19.1 and earlier, and on Pi, nothing changes.
- **Oh My Pi 19.2.0 refused Magic Context's background runs.** Summary and maintenance runs start a hidden Oh My Pi child with no tools. Oh My Pi 19.2.0 rejects the flag Magic Context used for that when an extension is loaded at startup. Hidden runs on Oh My Pi now ask for an empty tool list instead. The check that such a run really has no tools is unchanged.
- **The status screen and the todo list work on Oh My Pi 19.2.0.** Oh My Pi 19.2.0 also changed how extensions draw custom screens. `/ctx-status`, the todo list above the prompt and the todo tool's display now draw the new way on 19.2.0 and the old way on earlier versions and on Pi. If a host offers neither, Magic Context still loads and `/ctx-status` shows its summary as a plain notice.
