# v0.49.52

This patch fixes OpenCode 2 sessions that were refused on every turn with `MC-H04` once the conversation held a message without an id, and makes that refusal recover by itself when it still happens.

## Upgrading

Restart your host after updating. No database migration is needed.

## Fixed

- **OpenCode 2: `MC-H04` refused every turn, and `/ctx-recomp` could not clear it (issue 898, thanks @XA21X):** OpenCode 2 sends some messages without an id, such as its step-limit notice and a provider's own compaction checkpoint, and another plugin can add one too. One such message stopped Magic Context from removing the history its summaries already cover. When the conversation without that cut was larger than the model's window, the turn was refused, and every later turn with it. Magic Context now places these messages by the messages around them and makes the cut.
- **A history cut that still cannot be made no longer blocks the session:** when Magic Context cannot tell which loaded messages a summary covers and the request is over the window, it now summarizes further and tries again on the next send. If that cannot make room either, the refusal says what was wrong and what to do (`/ctx-flush` or sending again), in place of advising `/ctx-recomp`, which could not repair that state.
- **Dashboard: dismissing an already dismissed user memory changed its timestamp (issue 900, thanks @soarkit):** a repeated dismiss also told every open session that the user profile had changed. It now does nothing. The dashboard part ships with the next dashboard build.
