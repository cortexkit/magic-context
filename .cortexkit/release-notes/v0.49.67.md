# v0.49.67

This patch fixes Oh My Pi sessions that refused every turn after a provider stream error.

## Upgrading

Update the plugin and restart Oh My Pi. No database migration is needed.

## Fixed

- **Oh My Pi 19 refused every turn after a provider stream error (#951):** when a provider's stream failed after the model asked for a tool, Oh My Pi records a stand-in result saying the tool never ran. Oh My Pi 19 rewrites that result's text just before it sends the request, so the request no longer matched what Magic Context had prepared, and its safety check refused the turn. Every retry failed the same way. Magic Context now accepts Oh My Pi's rewritten text for that stand-in result only, identified by the markers Oh My Pi itself puts on it. Any other unexpected row is still refused. Sessions without such a result send exactly the same requests as before.
