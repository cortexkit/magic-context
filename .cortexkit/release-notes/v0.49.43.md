# v0.49.43

This patch fixes managed provider dispatch on Pi and Oh My Pi, including Cursor Agent requests.

## Upgrading

- Restart Pi or Oh My Pi after updating. No database migration is needed.

## Fixed

- **Oh My Pi refused Cursor turns but still sent them:** Magic Context now recognizes Cursor's conversation history and active user action, including the content-addressed history used by Oh My Pi. Managed Cursor requests can pass the dispatch fence without bypassing it. A refused request is replaced with a fail-closed payload before provider serialization instead of relying on a session abort that could still let the request through. The same backstop protects failed Pi preparations. Refusals retain their visible explanation, and unknown payloads identify the provider API and shape. Thanks to @Zireael for reporting refused Cursor turns whose tools still ran (#880).
