# v0.49.42

This patch stops superseded tool instructions from filling the context window on OpenCode 2.

## Upgrading

- Restart OpenCode after updating. No database migration is needed.

## Fixed

- **OpenCode 2 kept sending obsolete Code Mode catalogs:** restarting OpenCode or changing the available tools could leave dozens of old instruction updates in every request, consuming most of the context window before a host compaction ran. Magic Context now removes superseded instruction rows on a pass that is already rebuilding the prompt cache, including rebuilds triggered by high context usage. Each source must have a newer full restatement before its old row can go: incremental Code Mode updates, MCP guidance deltas, and unknown instruction sources stay. The decision survives restarts. On models whose reasoning signatures depend on the preceding conversation, removing a row also removes reasoning blocks invalidated by that edit. Manual compaction uses the same per-source rule. Thanks to @dhaern for the detailed report (#879).
