# v0.49.61

This patch makes Oh My Pi advisors work with Magic Context again on Oh My Pi 18.20.2 and later.

## Upgrading

Update the plugin and restart Oh My Pi. No database migration is needed.

## Fixed

- **Oh My Pi: every advisor turn refused, then the advisor halted (issue 940, thanks @Qiiks for the report):** Magic Context lets an Oh My Pi advisor's own requests through its safety check by recognising OMP's stock advisor prompt. Oh My Pi 18.20.2 removed the block that prompt used to start with, so on 18.20.2 and later no advisor was recognised, stock or customised, and each advisor turn was refused until OMP stopped the advisor. Magic Context now recognises the stock advisor prompt with or without that block. Your own `instructions:` in `WATCHDOG.yml` still work, because Oh My Pi adds them after the stock prompt. An advisor request after Oh My Pi compacts the advisor's own context is now recognised too; before, it was refused on every version. Main-session requests are checked exactly as before: a prompt you type that starts like an advisor update is still not treated as one.
