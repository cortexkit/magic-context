# v0.49.76

This patch fixes a set of bugs found in a review of the plugins for OpenCode, Pi and Oh My Pi. It also fixes a slowdown in the experimental Rust mode on very large sessions.

## Upgrading

Update the plugin with `npx @cortexkit/magic-context@latest doctor`, then restart OpenCode, Pi or Oh My Pi. No database migration is needed.

## Fixed

- **OpenCode 2: `/btw` could send the old text of a message you had edited.** A side question replays the conversation it was asked in. If you edited the last message it covered, and OpenCode's edit event arrived late, the replay could still send the text from before the edit. That includes text you removed on purpose. The replay now checks every message it sends against what OpenCode holds, including attachments, and skips the replay when anything differs. Hidden maintenance runs no longer prepare a replay at all, and the check is about 30% faster on long sessions.
- **`/ctx-wrapup` could report success and then not apply.** A wrap-up lets the next message apply the new summary. If another write to the same session's history happened at the same moment, the next message could send the old history, and the wrap-up was used up anyway. The summary then waited for an unrelated rebuild. The wrap-up now stays pending until a request actually carries its summary, on OpenCode 1, OpenCode 2, Pi and Oh My Pi. It is also used up when the history it raced with already includes the summary, so it never costs an extra cache rewrite.
- **Near the context limit, the emergency drop ignored images it removed.** When it turns a recent tool call into a short placeholder, the call's images go too. The drop did not count that saving. It could then keep a large screenshot and drop more tool outputs than it needed to. It now counts exactly what each drop removes.
- **OpenCode 2: automated host messages counted differently after a restart.** Messages OpenCode marks as automated were counted as your own messages in a live session, but not after OpenCode restored the session from a checkpoint. That shifted when older tool outputs were cleaned up. Both paths now treat them as automated.
- **Pi and Oh My Pi: screenshots counted at full size when judging how old a tool output is.** Old tool outputs are cleaned up once enough newer conversation follows them. A screenshot the model no longer sees, or that a text-only model never sees, counted as about 1,200 tokens of newer conversation. Images now count at what is actually sent.
- **Semantic memory search could keep retrying the same memories.** When some memories had no stored embedding, each search tried the same first 50 again. Memories after them never got an embedding, so a search by meaning could not find them. Each search now continues where the last one stopped, and the limits per search are unchanged.
- **Docs upkeep dropped corrections to oversized docs.** When a project's docs were already over the size budget, the nightly docs task dropped every proposed edit, even one that made the docs shorter. Edits that keep the size or shrink it are now kept.
- **Experimental Rust mode: very large sessions could time out.** One planning step scanned every message once for each assistant reply. On a session of about 31 MB it took over 90 seconds, so the request ran out of time. It now builds a lookup once and takes about 5 seconds.
