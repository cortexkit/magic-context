# v0.49.39

This patch makes automatic memory hints work for Chinese, Japanese and Korean prompts and for long memories.

## Upgrading

- Restart OpenCode or Pi after updating. No database migration is needed.

## Fixed

- **Memory hints were dropped for Chinese, Japanese and Korean prompts:** a memory hint appears only when the prompt and the memory share enough words. Text in these languages has no spaces, so a whole clause counted as one word and two clauses that shared most of their words still matched nothing. Hint scoring now compares such clauses by their overlapping character pairs and counts a clause as matched when at least half of them appear in the memory. Scores for space-separated languages are unchanged, and search ranking is unchanged. Thanks to @XWIlluDelu for the detailed report and reproduction (#874).
- **Memory hints ignored the end of long memories:** hint scoring read only the 220-character preview that search results display, so words further into a memory never counted. It now scores the full memory text, while search results still show the preview.
