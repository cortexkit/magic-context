# v0.49.71

This patch fixes the docs upkeep maintenance task, which failed on every run for projects whose docs have subsections.

## Upgrading

Update the plugin and restart OpenCode, Pi or Oh My Pi. No database migration is needed.

## Fixed

- **Docs upkeep failed on nested sections (#963, thanks @mgt-l):** the task treated every heading as the end of the section above it, so a section's `###` subsections didn't count as part of its `##` section. When the model proposed an update to a whole `##` section, including its subsections, the check refused it. One refused entry then discarded the whole proposal, and the task never moved past it, so it failed the same way on every run. A section now runs from its heading to the next heading of the same or a higher level (headings inside code blocks don't count). Replacing or removing a `##` section includes its subsections, and protected regions are still kept byte for byte. Each proposed change is now checked on its own: an invalid one is dropped with its reason recorded, the valid ones are kept, and the run completes and moves on.
