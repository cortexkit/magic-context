# v0.49.55

This patch stops the setup and doctor commands from starting a Pi session and sending a real model request every time they run on Pi.

## Upgrading

Update the CLI (`npx @cortexkit/magic-context@latest`). The plugins are unchanged and need no restart. No database migration is needed.

## Fixed

- **Pi: `doctor` and `setup` sent a real model request on every run (issue 911, thanks @maxdai):** to list your models, the CLI ran `pi --list-models` and also `pi models list`. Pi has no `models` subcommand, so it read those two words as a prompt, opened a new session and sent it to your default model. This happened on every `doctor`, `doctor --issue` and `setup` run on Pi, and each run then waited 20 seconds for that session to time out. The CLI now runs only `pi --list-models`. Sessions left by earlier runs, named after the prompt `models list`, can be deleted from Pi's session list.
