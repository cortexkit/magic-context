# v0.49.69

This patch stops the reduce reminders from asking the agent to drop conversation it was told to keep.

## Upgrading

Update the plugin and restart OpenCode, Pi or Oh My Pi. No database migration is needed.

## Fixed

- **Reduce reminders counted conversation as reclaimable (#954, thanks @iceteaSA):** the "Hygiene" reading in the sidebar, and the reminders built on it, counted your messages and the agent's own replies as something the agent could reduce. The `ctx_reduce` guidance tells the agent to keep exactly that text, so on a session that is mostly conversation the reading stayed high however well the agent reduced, and the reminders kept asking for reductions it isn't allowed to make. Conversation now counts toward the total but not toward what is reclaimable; tool output and files still do. This applies on OpenCode and Pi alike.
