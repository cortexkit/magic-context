# v0.49.45

This patch adds support for Claude Fable 5.2 and the Mythos models, stops Oh My Pi Codex sessions from refusing turns after a dropped reply, and stops `ctx_search` from waiting 30 seconds on an embedding endpoint that never answers.

## Upgrading

- Restart OpenCode or Pi after updating. No database migration is needed.

## Fixed

- **Claude Fable 5.2, Mythos 5.1 and Mythos 5.2 keep their reasoning valid:** on these models, a thinking block stays valid only while everything sent before it is unchanged, and Fable 5.2 and Mythos 5.2 enforce that on every account. Magic Context didn't know these models yet, so a rebuild could leave thinking in place that the provider then rejected with a 400 error. They now get the same handling as Fable 5.1 and the 5.5 models: when a turn rebuilds the prompt, the reasoning it would invalidate is removed first.
- **Oh My Pi with OpenAI Codex no longer refuses turns after a dropped reply:** when a reply Magic Context had dropped was replayed from Oh My Pi's stored copy, the stored copy could still hold the original text, or lose its `commentary` phase. The request check then refused the turn, and every later turn refused the same way. The placeholder now reaches the stored copy too, with that copy's own phase. A new check also refuses any request that would still carry a dropped reply's original text, including requests the turn comparison can't model, such as a turn from an earlier model. Turns that generated an image or ran a hosted web search are no longer refused. Thanks to @RiAnBee for the detailed report and reproduction (#887).
- **`ctx_search` no longer waits 30 seconds on a hung embedding endpoint:** when an embedding endpoint accepted connections but never answered, every search waited for the 30-second timeout, and the circuit breaker never opened. Failures are now counted from when their request started, so three hangs in a row open the breaker. A search also gives its query embedding 5 seconds before falling back to keyword search. Thanks to @iceteaSA for the report (#888).
- **Summaries keep the shell command:** a shell call without a description was summarized as a bare `TC: shell` (or `TC: bash` on Pi), so the agent couldn't tell what it had already run, and repeated its own reads. Summaries now fall back to the command itself, cut at 200 characters. Thanks to @dhaern for the report (#886).
- **`auto_update: false` turns off the update check:** with automatic updates turned off, the plugin still checked npm for a newer version. It now skips the check entirely. Thanks to @Oscar-Williams for the fix (#870).
