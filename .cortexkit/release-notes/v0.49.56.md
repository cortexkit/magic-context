# v0.49.56

This patch stops summaries and background memory work from waking your session on OpenCode 2.3, and lets very large Pi and Oh My Pi sessions take turns again.

## Upgrading

Update the plugin and restart the host. OpenCode 2 does not update npm plugins by itself, so update it as the docs describe. No database migration is needed.

## Fixed

- **OpenCode 2.3: summaries and memory upkeep woke your session (issue 913, thanks @HenrijsS for the report and @Neko-Yukari for the fix):** Magic Context writes summaries and runs its memory upkeep in hidden helper sessions. It created each one as a child of your session, and OpenCode 2.3 reports every finished child to its parent and starts a new turn there. So each summary and each upkeep run showed up as a message in your session, and your agent answered it. Hidden runs are now separate sessions with no parent. They are removed when they end. If a run is cut off by a crash or restart, a cleanup pass removes it later, at startup and every 30 minutes, once its own time limit has passed. Cleanup never removes a run that is still going. Checked on OpenCode 2.3.0 and on 2.0.22.
- **Pi and Oh My Pi: every turn refused on very large sessions (issue 920, thanks @snoproblem):** on a session with many thousands of tool calls, a one-time repair of duplicate tag numbers ran as one large step. It took longer than the turn's time limit, was undone, and started over on the next turn, so every turn was refused after about 35 seconds. The repair now saves its progress in small steps that each fit the limit, so a large session catches up over a few turns and stays fast after that. On a test session the size of the report, the first turn takes about 5 seconds and later turns about 25 milliseconds.
