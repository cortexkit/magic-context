# v0.49.37

This patch keeps images in an OpenCode 2.2 session's restored history after the host restarts.

## Upgrading

- Restart OpenCode after updating. No database migration is needed.

## Fixed

### OpenCode 2

- **Images in restored history were dropped after a restart on OpenCode 2.2:** after a fold, Magic Context rebuilds the kept messages, and each image needs OpenCode's own media object. On OpenCode 2.2, the fallback that builds one through OpenCode's schema didn't match the newer schema library, so it only worked after another image had passed through the same OpenCode process. After a restart, the first requests left those images out. Magic Context now builds them through both the newer and the older schema form, and keeps them byte for byte across a restart.
