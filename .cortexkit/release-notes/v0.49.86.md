# v0.49.86

This patch fixes a crash of the Magic Context sidebar in the OpenCode terminal, and makes the nightly memory check cover code inside git submodules.

## Upgrading

Update the plugin with `npx @cortexkit/magic-context@latest doctor`, then restart your host. No database migration is needed.

## Fixed

- **OpenCode terminal: the sidebar could crash after a status refresh** (issue 987, thanks @iceteaSA for the report and the fix). The sidebar read some status values without checking that they were present. When a refresh delivered a status without one of them, the sidebar crashed. It now checks every status value before it uses it and leaves out a part whose value is missing.
- **The nightly memory check skipped memories about code in git submodules** (issue 973, thanks @AyhamJo7 for the fix). To check a memory against the code, Magic Context lists the files that git tracks. That list did not include files inside submodules, so a memory about such a file was never checked, while the run still reported itself as complete. The list now includes the files of submodules. This applies to OpenCode, Pi and Oh My Pi.
