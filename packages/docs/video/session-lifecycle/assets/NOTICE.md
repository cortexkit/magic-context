# Local rendering assets

These assets are checked in so frame capture never needs a CDN request.

- `gsap.min.js`: GSAP 3.14.2, downloaded from https://cdn.jsdelivr.net/npm/gsap@3.14.2/dist/gsap.min.js. Copyright and the Standard License link are retained in the file header: https://gsap.com/standard-license/ . Only trailing whitespace was normalized; runtime code is unchanged.
- `inter-regular.woff2`, `inter-semibold.woff2`: Inter Latin 400 and 600 from `@fontsource/inter@5.2.8`, via jsDelivr. SIL Open Font License, included in `INTER-LICENSE.txt`.
- `roboto-mono.woff2`: Roboto Mono Latin 400 from `@fontsource/roboto-mono@5.2.6`, via jsDelivr. SIL Open Font License, included in `ROBOTO-MONO-LICENSE.txt`.

All graphics are original HTML/CSS. No generated images, music, voices, or remote runtime assets are used.
