# Broca export reader fixture

The Broca maintainers supplied these fixture files as a synthetic sample of
the `export_meta` / `export_facts` tables, generated by Broca's real export writer
at source snapshot `4bda042862fc903c41ffdd91e1e521b730e4312d`. The database, row
guide and checksum manifest are committed unchanged. No live store or real
session data was used. `fixture-rows.md` documents the eight rows and their generation.

`SHA256SUMS` lists the database and row guide's digests so accidental edits are
detectable; it also lists upstream contract documents and a SQL dump that are
not vendored here.

Rows 4 and 5 are one run of the `synthetic-agent-head` session exported as two
segments, ordinals 0 and 1, because the run's frozen prompt composition was
replaced mid-run; a reader must add them into one run.

Tests copy the database to a temporary directory before appending edge cases.
